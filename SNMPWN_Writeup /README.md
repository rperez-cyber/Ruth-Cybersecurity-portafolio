## **Herramientas utilizadas**
- Nmap - Reconocimiento y escaneo de puertos.
- onesixtyone - Enumeración de community strings SNMP.
- snmpwalk - Enumeración de información mediante SNMP.
- TFTP - Recuperación del archivo identificado.
- SSH - Acceso remoto al sistema.

  ### Una correcta configuración de SNMP, el control de la información accesible y una adecuada protección de servicios como TFTP pueden evitar que información sensible facilite el acceso no autorizado a un sistema.
