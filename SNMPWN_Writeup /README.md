### El objetivo de este laboratorio fue identificar y explotar una configuración insegura realcionada con el servicio SNMP.

## **Herramientas utilizadas**
- Nmap - Reconocimiento y escaneo de puertos.
- onesixtyone - Enumeración de community strings SNMP.
- snmpwalk - Enumeración de información mediante SNMP.
- TFTP - Recuperación del archivo identificado.
- SSH - Acceso remoto al sistema.
