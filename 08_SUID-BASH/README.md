# SUID-BASH

Laboratorio de escalada de privilegios en Linux en l aexplotación de un binario **Bash** con el bit **SUID**

## Información 
- **Plataforma:** Whoami-labs.com
- **Laboratorio:** SUID-BASH
- **Dificultad:** Básico - Intermedio
- **Sistema Operativo** Linux
- **Categoría:** Privilege Escaletion (SUID)

- ## Objetivo
- Identificar un binario Bash con el bit SUID activad, aprovechando el modo privilegiado (´-p´) para mantener el EUID de root y acceder al archivo ´flag.txt´

- ## Técnicas Utilizadas
- Enumeración interna
- Identificaci´on de binarios SUID
- abuso de Bash SUID
- Escalada de privilegios
- Captura de la flag

- ## Herramientas
- SSH
- Bash
- find
- id
- whoami
- cat
