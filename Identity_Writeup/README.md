## Objetivo
Identificar y explotar una vulnerabilidad de **Command Injection** en una aplicación web para ejecutar comandos arbitrarios, obtener acceso al sistema 
y escalar privilegios hasta **root**

## Herramientas utilizadas
- Nmap
- Gobuster
- Navegador web
- Bash

---
## Tecnicas utilizadas
- Enumeración de servicios
- Enumeración web
- Command Injection
- Enumeración de privilegios
- Escalada de privilegios
