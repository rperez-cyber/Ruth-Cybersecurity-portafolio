# Transferencia - Whoami-Labs
Laboratorio Linux donde se obtiene acceso inicial mediante un servidor FTP con acceso anónimo y posteriormente se realiza una escalada de privilegios explotando un binario SUID.

## Objetivo 
Comprometer la máquina y obtener privilegios de root.

## Herramientas

- Nmap
- FTP
- Hydra
- SSH
- Bash

- ## Técnicas
- 
- FTP Anonymous Login
- Credential Discovery
- Password Attack
- SSH Access
- SUID Enumeration
- Privilege Escalation
