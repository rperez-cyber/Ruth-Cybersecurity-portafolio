# Obejtivo
El objetivo de este laboratorio es identificar y explotar diferentes vulnerabilidades presentes en una aplicación web para conseguir acceso al sistema 
y realizar una escalada de privilegios hasta obtener la **flag**

- Gobuster
- Curl
