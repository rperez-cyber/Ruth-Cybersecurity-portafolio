# Laboratorio SUID - Privilege Escalation mediante SUID
Este repositorio contiene el writeup del laboratorio **SUID** de **Whoami-Labs**, donde se explota un binario con el bit **SUID** mal configurado de forma insegura
para escalar privilegios hasta **root**

## Objetivo
El propósito del laboratorio es identificar un binario SUID vulnerable y aprovecharlo para obtener privilegios elevados mediante un técnica de **Privilege Escalation**.

---

- SSH
- Find
- Linux
